What students can do
- Practise all 20 questions or select an individual topic (1.1–1.5).
- See the exam year and question number alongside each question.
- Answer single-choice and select-two multiple-choice questions.
- Receive an automatic score and percentage after submitting.
- See the correct answers and explanations.
- Click Try again as many times as they want.
- Shuffle the question order for each attempt.

The questions are paraphrased from the previously compiled past-paper index, with newly written answer options for practice.
